why I built this ▾
I built this to help people develop custom, personalized liquid glass UI, because AI can't do it yet. it hasn't been trained on liquid glass, so everything so far is reverse engineered, and it's good enough. this is a fun experiment, and a place to explore more forms of glass UI with the actual code behind it.
